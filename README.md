# 风里约行 · H5 本地体验版

原生 HTML / CSS / JavaScript，无构建依赖、无第三方 CDN、无后端。移动端五标签导航；桌面端侧栏、多列内容。路线资料与 9 张真实路线照片复制自原小程序，原项目未修改。

## 预览状态

仓库目前保持私有。GitHub 当前套餐不支持此私有仓库的 Pages，在线预览尚未启用；下载 `standalone.html` 可离线体验。

本仓库主版本已从微信小程序切换为 H5；旧小程序保留在 Git 历史提交 `9e8ee8a8522c6a4683fad092a3bf430070fa2029` 中，未接入其云开发服务。

## 运行

推荐通过静态服务打开（Python 标准库即可）：

```sh
cd fengli-youyue
python3 -m http.server 8080 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8080/`。不需要 npm install。

也可直接双击 `standalone.html`：样式、脚本及图片全部内嵌，不需要网络。部分浏览器限制 `file://` 的 localStorage，因此正式验证持久化请使用静态服务。单文件版与静态服务版的数据不保证互通。

修改源码后重新生成单文件：

```sh
python3 export_standalone.py
node --check app.js
node --check data.js
```

## 已实现的演示闭环

- 首页真实照片、心情入口、社区路线、邀约、自己的下一次待出发/进行中计划。
- 路线搜索（标题、介绍、区域、作者）、来源与心情组合筛选；详情、收藏、取消收藏。
- 采用为私人计划 → 编辑日期/名称/停靠点 → 手动开始 → 手动完成 → 保存/修改私人心得。采用同一路线时优先复用未完成计划。
- 手动创建路线，添加/删除停靠点（1–12 个）、自选封面、私密/公开开关。默认私密；主动公开有确认。
- 邀约详情 → 先查看发起人公开资料 → 再确认加入 → 成员本地聊天 → 退出。未加入者无法直接访问聊天；没有伪造回复。
- 发起人本机创建/关闭邀约；容量 2–12 人，含发起人；关闭和满员时禁止加入；关闭后聊天只读。不实现其他人的真实报名。
- 私密路线发起邀约前明确确认公开，计划/心得/私密照片不随之公开。
- 编辑昵称、简介、城市、步调、空闲时间、头像；选择最多 4 张公开介绍照片，发起人资料页仅显示公开字段和主动选定的照片。
- 独立私密照片库（最多 8 张），与公开介绍照片分开。所有上传仅接受 JPG/PNG/WebP，每张最大 800KB；保存为本地 data URL。浏览器配额不足时提示且回滚保存，不声称成功。
- 本地数据持久化、清空重置二次确认；hash 页面导航和浏览器返回；键盘可用的基础表单/对话框、状态提示、图片替代文本。

## 明确边界

1. 这是单浏览器、单用户、本地状态演示；没有账号、登录、数据库、同步、真实多人、实时聊天、通知、支付、定位或轨迹。
2. 顶部持续显示本地体验提示。加入不是向真人报名，聊天不会发送给其他设备，原有示例人物不在线也不会回复。
3. **AI 未接入接口，暂不可用。** 不做模拟生成、不使用虚构的生成结果，不包含任何 API 实现或凭据。
4. 所谓“公开”仅指本地的展示/可见范围标记，不会上传到网络。生成邀约会展示路线和发起人公开资料。私人计划、心得、私密照片不会进入公开资料页。用户输入不是加密存储，不应写入敏感信息。
5. 邀约中已使用的路线内容会继续显示；之后把路线改为私密不会撤回已创建的邀约信息，界面会提示。关闭邀约不会删除本地历史。
6. 所有数据存于 `localStorage`，多文件版键名 `fengli-h5-v1`，单文件版键名 `fengli-h5-standalone-v1`（彼此隔离）；清除浏览器数据不可恢复。不提供云备份。图片累计可能触及浏览器配额。
7. 示例路线的时间、费用、开放、季节与地址都不是实时信息。出行前自行核实开放/预约、天气和安全条件。示例邀约保留原项目的“周日 19:30”文案，不代表真实活动。
8. 仅静态文件交付；不部署、不连接原小程序接口，也不修改原项目。

## 文件

- `index.html` — 多文件版入口（主版本）
- `style.css` — 响应式视觉样式
- `app.js` — 页面、交互及本地状态逻辑
- `data.js` — 原项目示例路线/邀约内容的静态副本
- `assets/routes/*.jpg` — 9 张本地路线图片
- `export_standalone.py` — 标准库单文件导出器
- `standalone.html` — 可直接下载打开的自包含版本

## QA 建议

1. `#routes` → 打开任一路线 → 收藏 → 采用 → 编辑安排（添加/移除停靠点）→ 回到首页检查“我的下一次出发” → 开始 → 完成 → 私人心得 → 刷新检查持久化。
2. `#route-new` → 填写必填项和停靠点 → 默认私密保存 → 发起邀约（选择未来时间）→ 检查公开确认取消/确认两支 → 查看发起人公开资料 → 管理关闭 → 聊天只读。
3. `#invite/demo-invite-798` → 加入应先进入发起人资料 → 再确认加入 → 本地发送消息 → 刷新确认消息保留 → 退出 → 直接访问 `#chat/demo-invite-798` 应被拦截。
4. `#profile-edit` → 编辑空闲时间、上传头像和公开介绍照片 → 保存 → 查看自己创建邀约的发起人公开资料，仅显示选定公开照片；“我的 / 私密照片”不应出现。
5. 搜索/心情/来源组合无结果时显示空态；超过 800KB 图片报错；清空数据先取消再确认；`#me` 检查所有标签。

本版已进行 Chromium 浏览器交互及响应式布局检查；不等同于 iOS / Android 真机全量兼容性验证。
