# 风里约行｜微信小程序工程

> **项目状态：已归档（2026-08）**  
> 当前代码、CloudBase 数据模型、路线实拍资源与体验版实现均已保留，后续如重新启动，可从此仓库继续迭代。

## 当前完成内容
- 四个主页面：此刻、发现、创建、我的；
- 路线详情：路线时间线、保存到“我的周末”、独自出发与同行入口；
- 自定义底部 Tab Bar；
- CloudBase 云函数承载路线、收藏、同行计划与成员关系的真实读写。

## 重要边界
当前工程已接入 CloudBase 云函数；仍需在微信开发者工具中完成真机体验和发布前审核。

## 导入微信开发者工具
1. 打开微信开发者工具 → 导入项目；
2. 选择本目录：`/opt/data/fengli-yuexing-miniprogram`；
3. 工程已写入小程序 AppID；不要在项目或聊天中填写/发送 AppSecret；
4. 选择“小程序”项目类型并编译。

## 正式后端接入前置条件
1. 备案且可 HTTPS 访问的 API 域名；
2. 在微信公众平台配置“合法请求域名”；
3. 后端新增 `wx.login` code 换取 openid / unionid 的登录接口；
4. 将现有邮箱 Cookie 登录改为微信身份会话；
5. 接入真实路线、保存、同行申请与消息数据。

页面通过 `services/data.js` 调用 CloudBase `api` 云函数；请勿将持久化数据改回本地 storage。
