# 风里约行｜产品与 HIG 布局基准

## 产品一句话
帮助用户把任意一段空闲时间，变成一次由自己掌控的真实出发。

## 不是
- 不是路线瀑布流或伪实时内容社区。
- 不是陌生人社交或泛搭子平台。
- 不是 AI 替用户决定生活的自动执行器。

## 核心对象与关系

```text
路线（稳定内容/公开方案/AI 私密草稿）
      ↓ 用户采用
个人计划（用户自己的可编辑执行副本）
      ├─ 安排时间 → 自己去 → 完成 → 私密生活记录
      └─ 明确发起同行 → 邀约成员 → 路线私聊 → 完成 → 私密生活记录
```

- 路线是内容，不被采用者修改。
- 计划是用户行动层，允许编辑、安排、开始、完成。
- 邀约是关联某个计划的一次具体行动，绝不是路线的默认属性。
- 私聊只属于同一次邀约的成员。
- AI 的原始输入与生成草稿默认私密；公开必须由用户确认。

## HIG 布局规则

HIG 在本产品中意味着清晰、可读、可预期和可控，而不是灰底白卡模板。

1. 首屏只回答一个主问题：**我今天要不要出发？**
2. 若有未完成计划，计划是首要内容；若无，提供“AI 帮我开始”和“从路线库挑选”两个并列但不抢戏的入口。
3. 路线详情只做一件事：帮助用户决定是否采用为自己的计划。
4. 计划详情只做一件事：帮助用户完成自己的出发；同行是显式的次级分支。
5. 邀约列表先呈现行动条件（时间、地点、人数、节奏），再呈现社交操作。
6. 聊天只呈现本次行动的必要上下文，并在结束后清晰切换为只读。
7. 蓝色只用于可执行/可导航的语义；不把每张卡片都做成主要操作。
8. 优先使用大图、文本层级、分组、材料深度来建立节奏，避免功能入口平均铺开。

## 页面第一层信息

| 页面 | 首要信息 | 主要动作 | 次要动作 |
|---|---|---|---|
| 首页 | 下一次出发 / 今天怎么开始 | 打开计划或开始生成 | 浏览路线、查看同行 |
| 路线详情 | 这条路线是否适合我 | 采用为计划 | 查看同行 |
| AI 创建 | 这次想怎么过 | 生成私密路线 | 发布路线 |
| 计划详情 | 何时出发、如何完成 | 安排/开始/完成 | 编辑、发起同行 |
| 邀约 | 是否适合加入这一次行动 | 看主页/加入 | 查看路线 |
| 私聊 | 本次出发的集合信息 | 发送行动相关消息 | 举报/退出 |
| 我的 | 我的计划、邀约与记录 | 继续一个计划 | 编辑主页 |

## 发布门禁
UI 重构先走隔离预览与真实编译；未经视觉确认不上传新的开发版或体验版。
