# 风里约行｜已确认产品逻辑

## 核心对象

### 路线方案（Route）
可被浏览、采用和二次编辑的内容。来源只有三种：
- 系统内置精选路线：稳定模板；用户不能改原件。
- 用户公开发布的路线方案：可以只是一个地点/轻想法，也可以是完整多站路线。
- AI 个性化路线：先是私有草稿，用户可保存、公开发布或作为邀约基础。

路线字段：标题、地点或多站停留点、可选日期偏好、预算、交通、耗时、节奏、描述、公开性。

### 我的计划（Plan）
用户点击“采用这条路线”后得到的个人执行副本。所有来源的路线都会先变成计划，原路线不被修改。计划可独自执行、继续编辑、存为待决定，或作为邀约基础。

### 同行邀约（Invitation）
一次有明确时间的行动，必须关联到一个计划。创建时需要：日期/时间、集合地点、可参加人数上限（含发起人）、节奏、预算说明、补充说明。不能直接从空白状态发邀约；若用户只有一个地点/想法，先创建轻路线方案，再创建计划和邀约。

### 路线私聊（Conversation）
邀约内的私聊，服务于本次同行。聊天必须由参与者发起或加入邀约后才能进入；关联邀请和路线，不能成为全站陌生人私信。活动结束后聊天记录保留只读，后续可在新邀约中重新发起。

## 统一用户链路

```text
系统精选 / 用户发布 / AI 生成
        ↓ 采用
我的计划（私人副本）
        ├─ 自己去：设定时间后开始/完成，默认私密
        ├─ 先留着：待决定，可继续编辑
        └─ 发起同行邀约：补充时间、集合、人数组成等
                              ↓
                       有人申请 / 加入
                              ↓
                       邀约内路线私聊
                              ↓
                       出发 / 完成 / 留下足迹
```

## 首页和导航

一级导航：`首页 / 路线 / 发布 / 邀约 / 我的`。

- 首页：路线方案与同行邀约的精选摘要；AI 个性化生成入口。系统精选路线只是稳定内容底座，不做每次刷新的伪实时推荐。
- 路线：`系统精选 / 大家发布 / 为我生成`。
- 发布：`AI 生成路线 / 发布路线方案 / 发起同行邀约`。第三项先选择已有计划，或创建轻方案后再继续。
- 邀约：`正在邀约 / 我发起的 / 我参加的`；详情内可进入该邀约的路线私聊。
- 我的：`我的计划 / 草稿箱 / 我的邀约 / 足迹`。

## 权限与边界

- 采用路线只复制为个人计划，绝不修改来源路线。
- 自己去的计划默认不公开，不能被陌生人看见。
- AI 原始输入和个人偏好默认私密；公开时只公开用户确认后的路线内容。
- 邀约是基于计划的一次具体行动，同一路线可以有多次、不同用户的邀约。
- 邀约人数上限必须校验；发起人自动占一个名额。
- 私聊仅对邀约成员开放，并可举报、退出邀约；不提供任意用户的陌生人私信。
