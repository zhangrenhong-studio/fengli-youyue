# 风里约行 · v3 侧栏版

基于稳定的 v2 本地体验版重构布局；无后端、无账号、不产生真实报名或消息。未部署，原版与 v2 均保持不变。

## 使用

- 多文件版：用任意静态站点服务打开 `index.html`，保留同目录 `app.js`、`data.js`、`style.css` 和 `assets/`。
- 离线版：直接打开 `standalone.html`，全部九张路线图片与脚本样式均已内嵌，无外部依赖。
- 修改后重新导出：`python3 export_standalone.py`。
- 语法检查：`node --check app.js`。

## v3 页面结构

- 桌面使用固定 216px 浅色左侧栏（较窄桌面 210px），分「发现」「我的」两组。底部为创建路线和头像／编辑公开资料入口；不保留桌面顶部导航。
- 发现：首页、发现路线、同行邀约。我的：我的计划、我的收藏。
- 收藏直达 `#me?tab=bookmarks`，支持 `#bookmarks` 别名；`#me?tab=plans` 回到计划。收藏与计划不会同时高亮；链接刷新保留对应标签。
- 手机保留首页／发现路线／发布路线／同行邀约／我的计划五项底部导航，无侧栏空白。
- 首页为简洁标题与横向时间／预算／区域筛选；有未完成计划才显示横跨主内容的继续入口。下方为两列路线推荐与紧凑同行信息，无大幅空状态或首屏巨图。
- 路线发现最多三列，保留搜索、来源、心情、时间、预算、区域组合筛选及重置。
- 同行广场为横向信息列表：发起人、状态／容量、路线、时间、集合点、步调／时长、费用和详情入口。窄屏自然堆叠。
- 我的计划按正在出行／已安排／待安排／已完成分组，显示下一步动作。公开资料仅保留紧凑摘要；收藏、路线、邀约、私密照片标签继续保留。
- 路线详情保留内容＋桌面吸附操作面板，手机保留固定操作条。表单居中限制宽度，公开发起人页保留简介、介绍照片与空闲时间。

## 保留的行为与安全边界

多文件版继续使用本地键 `fengli-h5-v1`，兼容原有本地数据；离线导出使用独立键 `fengli-h5-standalone-v1`，避免导出内嵌图片与多文件路径互相污染。

原有数据清洗、事务回滚、私密默认、公开确认、计划采用／安排／开始／完成／私人心得、先查看发起人再加入、容量限制、成员聊天、退出权限守卫、关闭后只读、跨标签存储同步与重置逻辑均保留。未接入 AI、定位、地图导航或服务器。
